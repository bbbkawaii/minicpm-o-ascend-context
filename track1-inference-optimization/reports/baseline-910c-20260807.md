## Notes / gotchas

1. **Branch**: MUST use `minicpm-challenge` branch of vllm-omni. The default detached HEAD has a `AutoImageProcessor.register(str, ...)` bug with transformers 5.x.
2. **Registry subprocess crash**: `python -m vllm.model_executor.models.registry` aborts with `corrupted size vs. prev_size` because importing vllm-omni corrupts the heap at exit. Workaround: pre-generate modelinfo caches under `$VLLM_CACHE_ROOT/modelinfos/` (see `gen_all_modelinfo`), so the registry skips the subprocess check.
3. **Token2Wav deps**: `stepaudio2-minicpmo`, `step-audio2`, `s3tokenizer`, `onnx`, `ml-dtypes>=0.5`, `librosa`, `soundfile`, `hyperpyyaml` must all be installed.
4. **Network**: github.com direct access times out on this host; use `ghproxy.net` for git and `files.pythonhosted.org` via wget/pip-cache for wheels.
