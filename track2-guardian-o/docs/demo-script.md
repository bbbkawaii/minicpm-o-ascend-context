# Guardian-O 90 秒演示脚本

## 道具

- 护目镜
- 红色与蓝色标签的透明空容器
- 一张任务卡
- 普通桌面和摄像头
- 不使用任何真实危险材料

## 分镜

| 时间 | 操作 | 系统证明 |
|---:|---|---|
| 0–10 秒 | 打开 Guardian-O，选择“实验室安全演练”，展示服务运行在昇腾环境 | 可运行性、环境 |
| 10–20 秒 | 展示任务卡并开始会话 | 文本/OCR、任务理解 |
| 20–35 秒 | 未佩戴护目镜，伸手拿器材 | 持续视频理解、主动提醒 |
| 35–45 秒 | 佩戴护目镜，证据卡变为“已纠正” | 状态闭环 |
| 45–60 秒 | 故意拿红色标签容器 | 视觉与步骤联合理解 |
| 60–72 秒 | 助手说话时用户打断：“为什么不能用这个？” | 音频理解、打断、上下文回答 |
| 72–82 秒 | 换成蓝色容器并结束任务 | 纠正确认、会话结束 |
| 82–90 秒 | 展示操作报告和延迟指标 | 工程证据、可追溯性 |

## 必须一镜到底证明的内容

- 摄像头画面确实实时变化。
- 用户没有先点击“触发提醒”按钮。
- 打断发生在助手语音尚未结束时。
- 证据卡与报告来自本次会话。
- 页面明确显示当前是 Mock、Stable 还是 Realtime 模式。

## 失败兜底

- Realtime 不稳定：切换 Stable，仍完成全部业务闭环，并说明实验能力限制。
- 音频回声影响打断：使用耳机，并保留界面上的打断状态证据。
- 某个视觉事件未触发：保持道具位置、光照和任务卡格式一致；不得用隐藏按钮伪造模型事件。
