# 赛道二提交清单

## 可运行作品

- [ ] Web Demo 或 App 可以从干净环境启动
- [ ] 提供 Mock、Stable、Realtime 三种模式的能力边界说明
- [ ] Stable 模式不依赖实验性全双工路径
- [ ] 健康检查、错误状态和重启步骤清晰
- [ ] 不依赖赛道一目录中的任何文件或进程

## 项目说明

- [ ] 用户问题、目标用户和场景价值
- [ ] 完整用户流程
- [ ] MiniCPM-o 4.5 全模态能力的必要性
- [ ] 独立技术架构
- [ ] 昇腾环境和复现命令
- [ ] 安全边界、已知限制和降级方式
- [ ] 测试场景与结果

## PPT

- [ ] 问题与机会
- [ ] 产品方案与核心交互
- [ ] 90 秒演示闭环
- [ ] 模型能力与技术架构
- [ ] 昇腾适配与工程质量
- [ ] 测试数据和复现证据
- [ ] 场景价值与后续规划

## 视频

- [ ] 一镜到底展示实时画面
- [ ] 主动提醒不是按钮触发
- [ ] 展示用户语音打断
- [ ] 展示证据卡和最终报告
- [ ] 展示运行模式和昇腾环境
- [ ] 音画、字幕和页面内容清晰

## 提交包卫生

- [ ] 不含 `.env`、Token、Cookie 或账号信息
- [ ] 不含模型权重和超大日志
- [ ] 不含参赛者以外人员的脸、声音或个人信息
- [ ] 文件命名符合平台要求
- [ ] 压缩包在另一台机器上解压验证
- [ ] 记录最终 commit SHA 和依赖版本

## 官方待确认

- [ ] 同一参赛者同时参加两个赛道的规则已获得书面答复
- [ ] 最终硬件、镜像和 CANN 版本已更新
- [ ] 提交入口、截止时间、容量和视频格式已更新
