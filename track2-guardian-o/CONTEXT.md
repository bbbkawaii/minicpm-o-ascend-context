# 赛道二：Guardian-O

本项目描述一个在实验教学和安全演练中持续理解现场、主动介入并记录过程的全模态伴随助手。

## Language

**伴随会话**：
用户授权摄像头和麦克风后，助手持续理解现场、可以主动说话并接受打断的一段有开始和结束的交互。
_Avoid_: 监控、通话

**任务卡**：
定义本次演练目标、预期步骤和可观察检查点的输入材料。
_Avoid_: 提示词、实验说明书

**现场事件**：
在伴随会话中由模型观察到、并经过事件策略确认的步骤变化、遗漏或潜在风险。
_Avoid_: 告警、模型输出

**主动提醒**：
助手在用户没有提问时，因确认的现场事件而发起的简短语音和文本反馈。
_Avoid_: 自动报警

**证据卡**：
对现场事件的可视化记录，包含时间、观察、建议、状态和必要的画面证据。
_Avoid_: 日志、弹窗

**操作报告**：
伴随会话结束后形成的步骤、事件、纠正状态和改进建议摘要。
_Avoid_: 安全鉴定、合规报告

**演示降级模式**：
当实时全双工能力不可用时，仍能用分段音频和周期视频帧完成核心闭环的独立运行方式。
_Avoid_: 假 Demo、备用页面
